## 핵심 구조

- 프런트엔드: 상품 카드는 기존 요소로 구성하고, 카메라는 전용 부품으로 연결합니다.
- 백엔드: Spring Boot 또는 FastAPI가 상품 조회·인증·저장·AI 처리 API를 제공합니다.
