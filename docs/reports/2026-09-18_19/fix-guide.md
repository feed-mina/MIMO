## 4. 수정 또는 확인 방법

1. 이미지 파일과 리뷰 본문을 저장하는 계약을 먼저 분리해 확인합니다.
2. JSON 창구에는 JSON 직렬화한 본문과 맞는 헤더를 보내고, 파일 업로드는 해당 계약으로 처리합니다.
3. 성공 응답의 식별값을 반환하고 부모 목록을 다시 조회하도록 연결합니다. 실패 시 입력을 보존합니다.

## 5. 완료 기준

- [ ] 테스트용 닉네임과 본문을 저장하면 새 리뷰가 목록에 한 번 표시됩니다.
- [ ] 저장 실패 시 성공처럼 폼이 비워지지 않고 오류 안내가 나옵니다.
- [ ] 기존 리뷰 표시와 삭제의 실제 저장 여부가 명확히 구분됩니다.

## 6. 검증 방법과 제출할 근거

모의 저장 응답으로 성공·실패를 먼저 확인합니다. 외부 저장소 검증은 테스트용 프로젝트에서만 수행하고 요청 형식, 저장 식별값, 재조회 응답을 남깁니다.

실행 결과·캡처·응답 본문 중 완료 기준에 해당하는 근거를 남깁니다. 미실행 항목은 완료로 표시하지 않습니다.
